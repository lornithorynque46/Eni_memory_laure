Memory

Bienvenue sur le site du Memory de l'ENI !
Venez jouer avec nous et faites le meilleur score possible.

Règles du jeu:

  • Retournez deux cartes. Si les cartes sont identiques, le joueur laisse les cartes visibles.
  • Si les images sont différentes, les cartes se retournent faces cachéeslà où elles étaient.
  • La partie est terminée lorsque toutes les cartes ont été assemblées par paires.
